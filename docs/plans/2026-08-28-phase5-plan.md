**Fallback chain sketch:**
```ts
async function fetchViaScrapingAPI(url: string): Promise<string> {
  const key = process.env.SCRAPING_API_KEY; const provider = process.env.SCRAPING_API_PROVIDER||'scrapingbee';
  if (!key) throw new Error('SCRAPING_API_KEY missing');
  if (provider==='scrapingbee') return fetch(`https://app.scrapingbee.com/api/v1/?api_key=${key}&url=${encodeURIComponent(url)}&render_js=false`).then(r=>r.text());
  // scraperapi variant
}
```
In scrapeSource: if source.scrapingApi try fetchViaScrapingAPI first, catch → try Puppeteer if jsRendered else fetch. Record fetchMode in result.

**Verify:** `npm run typecheck` 0; unit test `tests/unit/scraper-fallback.test.ts` mocking fetch; build green. No real API key needed (branch skipped).
