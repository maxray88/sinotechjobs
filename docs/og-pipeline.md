# OG Pipeline — SinotechJobs ComfyUI + Fallback

> **Task:** T5.10 OG cards — 1200×630 Open Graph images for social sharing.
> **Outputs:** `public/media/og-home.png`, `public/media/og-jobs.png`, `public/media/og-article.png`
> **Workflow JSON:** `docs/og-pipeline.json` (ComfyUI graph) · **Fallback SVGs:** `public/media/og-home.svg` etc.
> **Generator script:** `scripts/generate-og.sh` · **Brand source:** `src/app/globals.css` CSS variables

## 1. Brand & Canvas

| Token | Value | Usage |
|-------|-------|-------|
| `--primary` | `#1e3a5f` | header, primary card border, title |
| `--primary-light` | `#2c5282` | gradient highlight |
| `--accent` | `#e11d48` | bottom 14px bar, pills, divider |
| `--accent-light` | `#f43f5e` | hover / secondary accent |
| `--muted` | `#f1f5f9` | article page background |
| `--foreground` | `#0f172a` | body title |
| `--border` | `#e2e8f0` | card strokes |
| `--background` | `#ffffff` | jobs page background |

- **Canvas:** 1200×630 (1.91:1) — Facebook / X / LinkedIn / Slack safe. Keep critical content inside 120px safe margin.
- **Font:** Geist Sans (`--font-geist-sans`) → fallback `Inter, system-ui, sans-serif` in SVG/PNG.
- **Bottom bar:** 14px solid `accent` at y=616–630 on every template for brand continuity.
- **File type:** PNG (preferred by crawlers). SVG fallbacks at `public/media/og-*.svg` are valid and served if PNG generation fails.

## 2. Workflow JSON Reference

`docs/og-pipeline.json` defines the ComfyUI graph:

- `CheckpointLoaderSimple` → `CLIPTextEncode` (positive `{{prompt}}` / negative `blurry, low quality, text artifact, watermark`) → `EmptyLatentImage 1200×630` → `KSampler (dpmpp_2m, karras, 28 steps, cfg 7, seed 42)` → `VAEDecode` → `ImageScale 1200×630 lanczos` → `SaveImage og-{{template}}`.
- Post-process node `Note` reminds to overlay the SVG text card with `satori` for crisp typography — ComfyUI raster text is blurry, so background is generated by ComfyUI and text is composited from SVG.

To import: ComfyUI → Queue → Load workflow → select `docs/og-pipeline.json` → replace `{{prompt}}` with the per-template prompt below.

## 4. Fallback via Satori (no ComfyUI)

When ComfyUI or GPU is unavailable, the repo serves **static fallbacks** with zero deps:

1. **SVG fallbacks** (`public/media/og-*.svg`) — 1200×630, pure SVG with brand tokens and system fonts. Valid `og:image` targets (Next.js will emit them if PNG missing; we keep PNG as primary and SVG as secondary `openGraph.images` alternative). Social crawlers that require PNG will use the PNG placeholder below.

2. **Node zlib PNG placeholders** (`public/media/og-*.png`) — generated via `node` stdlib only (`zlib.deflateSync`) by `/tmp/gen-png.mjs` (logic inlined in `scripts/generate-og.sh` comment). No `satori`/`sharp`/`canvas` needed. They are 1200×630 valid PNGs (signature `89 50 4E 47…`) with brand-accurate flat-color layouts approximating the SVG cards. Text is intentionally geometric (no font rasterization) — the SVG provides crisp text.

3. **Optional satori path** (if you add deps later):
   ```bash
   npm i satori @resvg/resvg-js
   npx tsx scripts/generate-og-satori.ts
   ```
   Example `generate-og-satori.ts` (not committed — scaffold):
   ```ts
   import fs from 'fs';
   import satori from 'satori';
   import { Resvg } from '@resvg/resvg-js';
   // import svg strings, call satori(<div style={{...}}>, {width:1200,height:630, fonts})
   // then new Resvg(svg).render().asPng() → write public/media/og-*.png
   ```

Current PNGs in repo are **placeholder-safe**: 21KB (home), 6.6KB (jobs), 7.3KB (article), each 1200×630, verified with `file public/media/og-*.png`.

## 5. ComfyUI Commands

See `scripts/generate-og.sh`:

```bash
# Full ComfyUI run (requires ComfyUI installed + checkpoint in models/checkpoints)
comfyui --workflow docs/og-pipeline.json --output public/media/

# Single template (example — home)
comfyui --workflow docs/og-pipeline.json --prompt-template home --output public/media/og-home.png

# Regenerate placeholders without ComfyUI (no deps)
node /tmp/gen-png.mjs  # or: bash scripts/generate-og.sh --fallback
```

To replace placeholders: run ComfyUI, copy `ComfyUI/output/og-*.png` → `public/media/`, keep the 14px accent bar and 120px safe margin.
